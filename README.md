# KTX 객실 LCD 안내화면 (웹 재현)

KTX 객실 LCD에 나오는 **출발 안내 → 노선도 → 정차역 안내 → 안전 안내** 화면을 웹 브라우저에서 재현한 팬 프로젝트입니다.
출발역·정차역·종착역을 자유롭게 정할 수 있고, 시각은 현재 시각과 실제 운행 기준 역간 소요시간으로 자동 계산됩니다.

> **바로 보기:** `https://<아이디>.github.io/<저장소이름>/`  ← GitHub Pages 주소로 바꿔 주세요

---

## SRT 버전

`srt.html`로 열면 SRT 객실 안내화면이 재생됩니다. (GitHub Pages: `https://<아이디>.github.io/<저장소이름>/srt.html`)

흰 화면 + SR 로고 → 화살표 두 묶음이 모임 → 쐐기 모양 띠로 펼쳐짐(소실점에 열차) → 띠가 짧아져 열차를 감쌈 → 열차가 다가옴(앞쪽 3/4) → 측면 통과 → 줄무늬 전환 → 3D 지도 위 노선(왼쪽 아래에서 띠 화살표 4개가 서해안 한 점으로 모임) → 카메라가 출발역으로 내려감 → 출발 깃발 → 노선 띠 + 정차역 링(출발역·정차역·종착역) → 도착 깃발 → 안내문 순서로 재생됩니다. 장면 길이와 위치는 실제 SRT 안내화면 영상을 프레임 단위로 재서 맞췄습니다.

- 화면 비율: 안내화면은 4:3(1024×768) 기준으로 만들어져 있습니다. 실제 16:9 SRT 화면은 이 4:3 화면을 **가로로 늘려서** 보여 주므로(깃발·로고·글씨가 모두 가로로 넓어짐), 가로 창(4:3~2:1)에서는 똑같이 가로로 늘립니다. 세로 창이나 아주 넓은 창은 늘리지 않고 남는 곳을 배경으로 채웁니다. `config.js`의 `screen.fit`: `'auto'` | `'stretch'` | `'fill'`.
- 지도: 노선은 실제 위치·실제 선로 모양 그대로 그립니다. 지도 구도는 실제 화면 두 개(2023-09-16 4:3, 2021-06-09 16:9)에서 잰 역 위치에 맞춰 자동으로 정합니다. 너무 붙은 역(창원·마산·창원중앙)만 실제 화면처럼 살짝 벌립니다.
- 설정은 `js/srt/config.js`에 따로 있습니다. 노선 설정창(`S` 키)도 KTX 버전과 따로 저장됩니다.
- 넣을 파일: `images/sr_ci.svg` (SR CI), `images/sr_bi.svg` (SR BI), `models/SRT_MODELING.glb` (경로는 config에서 변경 가능)
- SR BI는 흰색 SVG를 `assets.biColor`(기본 `#4B2F48`) 색으로 칠해서 보여 줍니다. 원래 색 그대로 쓰려면 `biColor: null`.
- 글꼴: 나눔바른고딕(대부분), 맑은 고딕('정차역 안내'). PC에 설치된 글꼴을 먼저 쓰고, 없으면 `fonts/NanumBarunGothic.ttf`, `fonts/NanumBarunGothicBold.ttf`, `fonts/NanumBarunGothicLight.ttf`, `fonts/malgun.ttf` 파일, 그다음 웹 글꼴(나눔바른고딕)을 씁니다.
- 링 색: 출발역은 분홍·파랑이 함께 도는 링, `pinkStations` 목록의 역은 분홍, 나머지는 파랑. 역마다 `ringColor: 'mix' | 'pink' | 'blue'`로 바꿀 수 있습니다.
- 디버그: `?start=train | map | flag | stops | arrival | notice` (그 장면부터 재생)
- 한 장면 멈춤 보기: `?freeze=intro:1.0` (첫 애니메이션, 화살표 묶음이 나타난 뒤 초) · `?freeze=side:0.8` (측면 통과) · `?freeze=map:5` (지도)
- **기본 노선 = 영상 그대로:** 2023-09-16 SRT 363 수서(오후 07:25) → 진주(오후 10:58). 정차역 11곳, 통과역 천안아산·김천(구미). 시각은 `times.mode: 'manual'`로 영상 시각을 그대로 씁니다. 현재 시각 기준으로 바꾸려면 `'auto'`.
- **통과역:** 정차역에 `pass: true`를 적으면 지도·오른쪽 노선 띠에만 나오고 링·시각은 없습니다. 설정창(`S`)의 **통과** 체크로도 바꿀 수 있습니다. `label`은 지도·노선 띠 표기(예: `김천(구미)`)입니다.
- **약도:** 지도 위 노선과 오른쪽 노선 띠는 영상처럼 역 사이를 직선으로 잇고, 붙은 역(창원·마산·창원중앙 등)은 간격을 벌려 그립니다. 노선 띠에서 지금 역 이름은 크게 분홍색으로 표시합니다.
- **안내문:** 영상에는 없으므로 기본은 꺼져 있습니다(`notice.enabled`). 도착 깃발 뒤 처음으로 돌아갑니다.
- 예전에 설정창에서 [적용]한 노선이 브라우저에 저장돼 있으면 그 노선이 먼저 나옵니다. 설정창에서 [기본값] → [적용]을 누르세요.

## 화면 구성

| 순서 | 화면 | 내용 |
|---|---|---|
| 1 | **출발 안내 (3D)** | 출발역이 있는 시군구가 지도에서 3D로 솟아오르고, 역명판이 함께 올라온 뒤 출발 카드(행선지·출발시각)가 펼쳐짐 → 고가 선로를 달리는 열차 |
| 2 | **노선도** | 한반도 지도에서 노선이 역 순서대로 그려지고, 역마다 빨간 점이 통통 튀며 나타남 |
| 3 | **정차역 안내** | 캐릭터 원이 실제 노선 경로를 따라 점선을 그리며 이동 → 역에 도착하면 6분할 링이 회전하며 피어나고 역명·도착시각 표시 |
| 4 | **안전 안내** | 안내 문구 스크롤과 하단 신고 전화 띠 |

화면은 **반응형**입니다. 어떤 비율의 창이든 여백 없이 꽉 채우고, 휴대폰 세로 화면에서는 정차역 안내가 위(링)·아래(정보 바) 구성으로 바뀝니다.

## 주요 기능

- **노선 자유 지정** — 화면에서 `S` 키로 설정창을 열어 출발역·정차역·종착역을 바꿀 수 있습니다.
- **시각 자동 계산** — 출발시각은 현재 시각, 이후 역은 노선별 역간 소요시간표와 정차시간으로 계산합니다. 직접 입력으로 바꿀 수도 있습니다.
- **역 데이터 약 120개** — KTX·SRT·KTX-이음 주요 역과 공항철도, 개통 예정인 서해선·장항선 역까지. 영문 표기·한자·좌표·도(道) 이름이 자동으로 채워집니다.
- **실제 노선 경로** — 지도와 정차역 화면의 이동 경로가 중간역 위치를 따라 그려집니다.
- **3D 모델 교체** — 역명판·열차를 직접 만든 glb 모델로 바꿀 수 있고, 크기·방향·객차 분리를 자동으로 맞춥니다.
- **링크 공유** — 설정창의 [링크 복사]로 노선이 담긴 주소를 만들어 공유할 수 있습니다.

## 실행 방법

### 온라인 (GitHub Pages)

저장소 **Settings → Pages**에서 Branch를 `main` / `/(root)`로 정하고 저장하면, 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/`에서 열립니다.

### 내 컴퓨터에서

`index.html`을 더블클릭하면 브라우저 보안 때문에 모듈과 모델 파일을 불러오지 못합니다. 아래 방법 중 하나로 로컬 서버를 켜서 여세요.

- **VS Code:** 확장 **Live Server**를 설치하고 `index.html`을 우클릭 → **Open with Live Server**
- **Python:** 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속
- **Node.js:** 폴더에서 `npx serve -l 8000` 실행 후 `http://localhost:8000` 접속

three.js와 웹 글꼴을 CDN에서 받아오므로 인터넷 연결이 필요합니다.

## 사용법

### 노선 설정창 (`S` 키)

화면을 한 번 클릭한 뒤 `S` 키를 누르면 설정창이 열립니다. `S` 또는 `Esc`로 닫습니다.
휴대폰·태블릿에서는 **화면을 길게(약 0.7초) 누르면** 열립니다.

- 역 이름은 목록에서 고르거나 직접 입력합니다. 목록에 없는 역은 영문·위도·경도 칸이 나타납니다.
- 정차역은 **[+ 정차역 추가]**로 늘리고, ▲▼로 순서를 바꾸고, ✕로 지웁니다.
- **출발·도착 시각 직접 입력**을 끄면 현재 시각 기준으로 자동 계산하고, 켜면 입력한 시각을 그대로 씁니다.
- **[적용]**은 브라우저에 저장하고 처음부터 다시 재생합니다. **[기본값]**은 `config.js` 노선으로 되돌립니다.
- **[링크 복사]**는 지금 노선이 담긴 주소를 복사합니다.

### 단축키 · 주소 옵션

| 키 / 주소 | 동작 |
|---|---|
| `S` / 길게 누르기 | 노선 설정창 열기 / 닫기 |
| `R` | 처음부터 다시 재생 |
| `?start=map` | 노선도부터 시작 |
| `?start=stops` | 정차역 안내부터 시작 |
| `?start=notice` | 안전 안내부터 시작 |
| `?freeze=7.5` | 출발 안내 7.5초 장면에서 멈춤 (모델 위치 확인용) |
| `?start=map&mapfreeze=6` | 노선도 6초 장면에서 멈춤 |

## 직접 고치기

대부분의 설정은 `js/config.js` 한 파일에 있습니다.

### 기본 노선

```js
route: {
  origin:      { name: '수서', depart: '14:30' },
  stops: [
    { name: '평택지제', arrive: '14:50' },
    { name: '천안아산', arrive: '15:03' },
  ],
  destination: { name: '부산', arrive: '16:56' },
},
```

역에 아래 값을 직접 적으면 자동값보다 우선합니다.

| 항목 | 설명 |
|---|---|
| `en`, `hanja` | 영문 표기, 역명판 한자 |
| `lat`, `lon` | 좌표 (목록에 없는 역은 필수) |
| `province` | 링 가운데 도 이름 |
| `sub`, `subEn` | 괄호 표기 (예: 울산역**(통도사)**) |
| `via` | 이전 역 → 이 역 사이 경유점 `[[위도, 경도], ...]` |
| `labelSide` | 노선도에서 역 이름 위치 `'left'` / `'right'` |

### 시각

```js
times: { mode: 'auto', dwell: 1 },   // 'auto' = 현재 시각 기준 자동 / 'manual' = 입력한 시각
clock: { mode: 'live' },             // 좌상단 시계: 현재 시각
```

### 역 목록 · 소요시간표

| 파일 | 내용 |
|---|---|
| `js/data/stations.js` | 역 이름 → 영문·한자·좌표. 역을 추가하려면 여기에 한 줄 넣으세요. |
| `js/data/travelTimes.js` | 노선별로 이웃한 두 역 사이 주행시간(분). 이어진 역끼리는 자동 합산하고, 통과역 1곳당 2분씩 뺍니다. |

> 소요시간은 공개 시간표와 실제 안내화면 영상 시각을 바탕으로 맞춘 **근사값**이며, 개통 전 노선은 추정치입니다.
> 정확히 맞추고 싶은 구간은 숫자를 직접 고쳐 주세요.

### 3D 모델

`js/config.js`의 `models`에서 파일 경로를 정합니다. 파일이 없으면 기본 도형으로 대체됩니다.

```js
models: {
  stationSign: { url: 'models/STATION_NAMEPLATE_MODELING.glb', height: 3.2, rotationY: 0, textMode: 'auto' },
  train:       { url: 'models/KTX_MODELING.glb', height: 4.0, forwardAxis: 'auto', carCount: 0 },
},
```

- **크기:** 역명판은 높이, 열차는 차체 높이(기본 4m) 기준으로 자동 스케일합니다. 로블록스 Baseplate처럼 넓은 판이나 멀리 떨어진 파트는 자동으로 제외합니다.
- **방향:** 열차는 끝이 뾰족한 쪽을 앞머리로 판단합니다. 거꾸로 달리면 `forwardAxis`를 `'x'`, `'-x'`, `'z'`, `'-z'` 중 하나로 지정하세요.
- **곡선 주행:** 객차 사이 틈을 찾아 객차별로 나눠 곡선에서 따로 꺾이게 합니다. 수가 다르면 `carCount`로 지정하세요.
- **역명판 글씨:** 모델에서 파란 판을 찾아 출발역 이름을 자동으로 붙입니다. 모델에 글씨가 이미 있으면 `textMode: 'none'`.

브라우저 개발자 도구(F12) → Console에 `[KTX LCD]`로 시작하는 진단 메시지가 출력됩니다.

### 글꼴

출발 화면과 정차역 안내에는 **서울남산체**를 씁니다. `fonts/SeoulNamsanM.woff`(보통 굵기)가 포함되어 있습니다.
굵은 글씨를 진짜 B / EB 굵기로 쓰려면 서울시 서울서체 배포 페이지에서 받은 파일을 `fonts/SeoulNamsanB.ttf`, `fonts/SeoulNamsanEB.ttf`로 넣으세요.

### 이동 캐릭터 이미지

정차역 화면에서 움직이는 원 안의 이미지는 `config.js`의 `character`에서 지정합니다.
이미지가 없으면 기본 열차 아이콘을 씁니다.

```js
character: { image: 'images/character.png', centerX: 236, centerY: 192, size: 175, flipX: true },
```
